# Logos

## Knowledge Architecture

Documentation follows five conceptual layers, progressing from general principles to concrete engineering reality:

1. **Governance — `LOGOS.md`**: Defines how the knowledge system is organized and governed.
2. **Direction — `VISION.md`**: Defines the project's purpose and long-term direction.
3. **Intent — `intents/`**: Expresses the goals and problems derived from the Vision.
4. **Control — `control/`**: Records the decisions, priorities, and plans for pursuing those intents.
5. **Engineering Reality — `engineering/`**: Records actual implementation, technical behavior, and verification evidence.

The relationship is progressive, not procedural: each layer provides context for the next, forming the structure `LOGOS.md → VISION.md → intents/ → control/ → engineering/`.

This is not a mandatory workflow or a one-to-one document mapping. Knowledge also evolves through feedback: engineering evidence may challenge decisions, intents, and ultimately the Vision.
